# Mi Proyecto Web

Bienvenido a este proyecto web moderno y responsivo. Una página web completa con HTML, CSS y JavaScript que demuestra buenas prácticas de desarrollo web.

## 📋 Descripción

Este proyecto es una plantilla web lista para usar que incluye:

- **HTML5 semántico**: Estructura bien organizada y accesible
- **CSS3 moderno**: Diseño responsivo con flexbox y grid
- **JavaScript dinámico**: Interactividad en tiempo real
- **Responsive Design**: Se adapta perfectamente a cualquier dispositivo

## 🚀 Características

- ✨ Diseño moderno y atractivo
- 📱 Completamente responsivo (mobile, tablet, desktop)
- ♿ Accesible y fácil de usar
- ⚡ Carga rápida y optimizada
- 🎨 Colores y tipografía profesionales
- 🔧 Código limpio y bien documentado

## 📁 Estructura del Proyecto

```
.
├── index.html      # Página principal HTML
├── index.css       # Estilos y diseño
├── index.js        # Funcionalidad interactiva
└── README.md       # Este archivo
```

### Descripción de archivos

**index.html**
- Contiene la estructura principal de la página
- Secciones: Header, Hero, Características, Contacto, Footer
- Vincula los archivos CSS y JavaScript

**index.css**
- Estilos para todos los elementos de la página
- Variables CSS para colores personalizables
- Media queries para responsive design
- Animaciones y transiciones suaves

**index.js**
- Manejo del formulario de contacto
- Navegación suave entre secciones
- Interactividad del botón principal
- Logging de eventos y detalles de depuración

## 🎯 Cómo Usar

### Opción 1: Descarga local
1. Clona o descarga este repositorio
2. Abre `index.html` en tu navegador web
3. ¡Listo! La página está funcionando

### Opción 2: Despliega en GitHub Pages
1. Sube este proyecto a tu repositorio de GitHub
2. Ve a Settings → Pages
3. Selecciona la rama `main` como fuente
4. Tu página estará disponible en `https://tu-usuario.github.io/nombre-repositorio`

## 🛠️ Personalizacion

### Cambiar colores
Edita las variables CSS en `index.css`:

```css
:root {
    --primary-color: #3498db;
    --secondary-color: #2ecc71;
    --dark-color: #2c3e50;
    --light-color: #ecf0f1;
    --text-color: #333;
}
```

### Modificar contenido
- Actualiza el texto en `index.html`
- Cambia los títulos, descripciones y el contenido de las secciones
- Personaliza el formulario de contacto

### Agregar más secciones
Copia la estructura de una sección existente y ajusta según necesites.

## 📞 Formulario de Contacto

El formulario incluye validación básica. Actualmente muestra un mensaje de confirmación. Para enviar emails reales, necesitarías:

1. Un backend (Node.js, Python, etc.)
2. Un servicio como Formspree, Basin, o similar
3. Configurar las credenciales adecuadas
